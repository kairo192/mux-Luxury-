# Mus Luxury (LUXE) — Storefront Architecture & Deployment Guide

**Application:** Public Boutique Web Storefront (`apps/storefront/`)  
**Domain:** `https://mus-luxury.com` (Alias: `https://www.mus-luxury.com`)  
**Tech Stack:** React 18, Vite 5.4, TypeScript, Tailwind CSS

---

## 1. Architecture & Styling Engine

### 1.1 Pure Build-Time Tailwind (Zero Runtime CDN)
In previous development iterations, Tailwind was loaded via a client-side JIT script (`https://cdn.tailwindcss.com`). This violated production Content-Security-Policy (CSP) headers and caused unstyled rendering in strict browsers.

In production:
- Tailwind colors (`emerald.*`, `gold.*`, `cream.*`), luxury fonts, and custom box shadows are compiled into a pure CSS bundle via `tailwind.config.js` and `src/index.css`.
- The production build emits an optimized ~42 KB CSS bundle (7.5 KB gzipped).
- Zero external CDN dependencies; 100% compliant with strict `script-src 'self'` CSP policies.

### 1.2 Internationalization & RTL Support
The storefront supports three languages:
1. **Français (FR):** Default luxury presentation.
2. **العربية (AR):** Full Right-To-Left (RTL) layout switching via `dir="rtl"` attribute.
3. **English (EN):** International tourist / diplomat presentation.

Language state is persisted in localStorage and reactive across all components without full-page reloads.

## 2. Multi-Stage Docker Build (`apps/storefront/Dockerfile`)

The storefront builds inside an isolated Node.js container and is served via an ultra-lightweight Nginx container:

```dockerfile
FROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm install --no-audit --no-fund
COPY . .
RUN npm run build

FROM nginx:1.27-alpine
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
HEALTHCHECK --interval=15s --timeout=5s --retries=3 CMD wget -qO- http://127.0.0.1:80/ >/dev/null || exit 1
CMD ["nginx", "-g", "daemon off;"]
```

Memory footprint in production: **~9 MB RAM**.

## 3. Production Caching Strategy (Nginx)

Static assets generated by Vite include cryptographic content hashes in filenames (e.g. `assets/index-VUELEGZt.css`):

```nginx
# Storefront static assets (Vite chunk hashed assets with immutable caching)
location /assets/ {
    proxy_pass http://storefront:80;
    expires 30d;
    add_header Cache-Control "public, max-age=2592000, immutable" always;
}

# HTML document (Always revalidate so updates are instant)
location / {
    proxy_pass http://storefront:80;
    add_header Cache-Control "no-cache, must-revalidate" always;
}
```

## 4. Cash-On-Delivery (COD) Order Flow

Algerian retail e-commerce relies overwhelmingly on Cash-on-Delivery with Wilaya-based shipping tariffs:

1. Customer selects product variants (color, size) and adds to cart.
2. At checkout, selects their Algerian Wilaya (1 to 58).
3. The storefront fetches verified delivery rates from `/api/v1/delivery-rates`. Customer shipping fees are calculated server-side and rendered read-only.
4. Customer enters verified Algerian phone number (`05`, `06`, `07`, or `+213`).
5. Order payload is submitted to `POST /api/v1/orders`.
6. Rate limiting on Nginx protects against automated checkout spam (10 orders/min per IP).
7. Stock quantities are decremented atomically with row-level locks, preventing overselling.
